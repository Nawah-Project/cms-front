# المرحلة التالية: حفظ الحساب والتخزين والنشر

هذا تصميم تنفيذ لاحق، وليس وصفًا لخدمات منشورة. يبدأ بعد مراجعة تجربة القارئ والعروض في `learning-library.md`.

## الملكية وحدود المجال

`LearningLibraryModule` في cms-back، بمستودع خاص وعمليات تملك كتب/طبعات/ملاحظات/خرائط/أحداث قراءة/أهداف/مراجعات/ملفات. لا إضافة هذه العمليات إلى AdminService، ولا دخول مباشر إلى جداول Journey أو الاستشارة أو CV. هوية المالك تأتي من المصادقة، ولا يقبل API مالكًا حرًا من الجسم. الحساب المؤكد وصلاحية LEARNING_LIBRARY ثم الملكية مطلوبة؛ Root هو أول مستخدم، ومنح أي صلاحية لاحقًا عملية منفصلة. READ لا يكتب سجلات أو أحداث قراءة أو ملفات. لا تفترض أن كل أدمن يقرأ مكتبة Root.

الملاحظات والملفات خاصة، ولا تُرسل إلى Marketing أو UX Lab، ولا تدخل نصوصها في logs أو telemetry. التدقيق يحفظ معرف العملية ونتيجتها وتوقيتها دون المحتوى.

## عقد الحفظ

API تحت `/admin/learning-library` مع `GET` للمكتبة وعقود CRUD محددة للكتب والطبعات والملاحظات والخرائط والأهداف والقراءة. عمليات إنشاء بمعرف محاولة ثابت، والتعديل برقم مراجعة؛ 409 عند التعارض مع إبقاء المسودة في العميل. المحول المحلي لا يُستخدم عند تعطل الشبكة باعتباره نجاح حساب بديلًا. تحقق DTO وخدمة المجال في Backend مستقل عن تحقق الواجهة.

النسخة المحلية الحالية تجمع السجلات في document وتستخدم رقم مراجعة واحدًا لتجربة التعارض. حفظ الحساب يفصل الجداول والسجلات والمعاملات ويضع قيود uniqueness للمالك+بصمة الطبعة ولطلبات التكرار، ويحدد نتائج التعارض لكل مورد. راجع حفظ أحداث القراءة على نطاقات كثيرة قبل تحويله إلى عقد API نهائي.

تظل الهوية الثابتة للكتاب مختلفة عن هوية الطبعة والملف. حذف ملف لا يحذف الكتاب أو ملاحظاته. ملف مختلف أو طبعة جديدة لا يعيدان كتابة anchors القديمة تلقائيًا. الحذف النهائي يحتاج سياسة مستقلة وتأكيدًا ومعالجة المراجع؛ الأرشفة هي الخيار الاعتيادي.

## الملفات الهجينة

لا رفع عند اختيار PDF محلي. تحفظ نسخة السيرفر فقط بعد اختيار صريح للكتاب. مساحة خاصة لا تقع تحت public أو مخزن CV، وحصة مستقلة 20GiB/مالك، وحد كتاب 500MiB قابلان للضبط. يُحجز حجم التحميل النشط داخل الحصة لمنع تجاوزها بالتوازي، ولا تُعتمد البصمة المرسلة من العميل دون إعادة التحقق.

بروتوكول upload: بدء محاولة، عرض offset المقبول، إرسال أجزاء صغيرة متتالية، التحقق من offset وبصمة الجزء، إنهاء الملف والتحقق من PDF والحجم والبصمة النهائية، ثم ربطه بالطبعة. محاولات مكررة لا تكرر الأجزاء أو خصم الحصة. تنزيل/رفع واحد نشط بمعدل ابتدائي 1MiB/s؛ لا تعتمد على مؤقت واجهة وحده لضبط سرعة السيرفر. توقف التحميل أو انتهاء الجلسة لا ينشئ كتابًا «متاحًا» بملف ناقص.

التحميل وطلبات HTTP Range تفحص المالك والصلاحية، وتُرجع `Cache-Control: private, no-store`، ولا توجد روابط ملفات عامة أو مسار حقيقي مكشوف. لا تتشارك سياسة تنظيف CV القديمة مع هذا المخزن. تفحص الاختبارات إرجاع صورة التطبيق القديمة دون أن يحذف منظفها ملفات المكتبة.

الاستيراد المجمع يقتصر على inbox مهيأ خارج public ينقل إليه المالك عبر SSH/SFTP الموجود. السيرفر يعرض مراجع مرشحة فقط؛ لا API يقبل مسارًا عشوائيًا، ولا symlink خارج inbox، ولا اعتماد تلقائي للملفات. إعادة تحقق البصمة والحجم والحصة وقت الاعتماد. لا تعديل DNS/HTTPS محلي ضمن هذا العمل.

## التكامل

مساحة المؤسس تملك المهام والجدولة والسعة. هدف قراءة يحمل مرجع مهمة؛ إنشاء مهمة جديدة فعل صريح من عقد عمليات المؤسس مع صلاحياته، لا Prisma مشترك ولا نسخ خطة. مراجع العلاقات والاستشارة تشير إلى book/edition/page فقط. لا تنسخ ملاحظات الأشخاص أو الحالات إلى المكتبة. تعطل التكامل لا يمنع القراءة أو تدوين الملاحظات.

## بوابات القبول والنشر

- مستخدم/أدمن غير مخول ممنوع، READ يمنع كل POST/PATCH/DELETE ورفع أجزاء، ومكتبة مالك آخر وملفاتها لا تُكشف عبر IDs أو ranges أو استيراد.
- بيانات الملاحظات وطبعات الملفات تبقى عند إزالة الملف، وفشل الحفظ والتعارض والتكرار لا يفقد مسودات أو يكرر السجلات.
- انقطاع رفع فعلي ثم استكمال، جزء ببصمة خاطئة، offset خاطئ، ملف فوق الحصة، سباق محاولتين، Range لملف مالك آخر.
- تصدير خاص بالمالك واستعادة بعد تحقق البنية والمراجع والأحجام. لا تسوية تلقائية للطبعات المختلفة.
- backup PostgreSQL مع manifest للملفات وبصماتها، واستعادة معزولة متحقق منها قبل أول نشر. صلاحيات ومسارات وملاحظات الإنتاج لا تستخدم كبيانات اختبار.
- ترحيلات إضافية متوافقة. بناء member/admin/API على GitHub، اعتماد المكون المتغير فقط، عبر مسار النشر الحالي. لا نشر من خادم DEV.
- الصحة وواجهة المستخدم والصلاحيات وتوفر النسخ وJourney/الاستشارة/المؤسس والعلاقات الحالية بعد النشر. الرجوع لصورة لا يتراجع تلقائيًا عن migrations؛ تبقى سجلات وملفات المكتبة الجديدة محفوظة.

لا تُعتبر الخطة كاملة أو منشورة حتى تنجح هذه البوابات في مراحلها، ويُسلم تقرير إصدار فعلي بمراجع الصور ونتائج التحقق.
